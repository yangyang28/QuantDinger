# AI 智能交易机器人 — 产品说明

版本：v0.1 Draft  
标的：黄金（XAU）+ 加密货币（BTC / ETH 为主，可选 SOL 等）  
状态：产品设计稿（非投资建议；实盘前须完成回测、仿真与风控验收）

---

## 1. 产品一句话

用**顶尖金融/交易推理模型**做「技术面 × 消息面 × 事件面 × 情绪面」实时研判，输出行情状态；再用**规则引擎**严格执行三套策略（黄金费率套利 / 箱体机会单 / 震荡网格），实现**可解释、可熔断、可审计**的半自动～全自动交易系统。

---

## 2. 核心设计原则（可行性关键）

| 原则         | 说明                                                        |
| ---------- | --------------------------------------------------------- |
| AI 不直接裸下单  | 模型只输出：行情状态、信号置信度、建议策略与风险提示；**成交指令由规则引擎校验后执行**             |
| 状态机优先      | 先判 `ARBITRAGE / TREND / RANGE / RISK_OFF`，再启用对应策略；状态错了不开仓 |
| 硬风控不可被模型覆盖 | 止损、熔断、单笔风险、日亏损上限、杠杆上限由代码强制执行                              |
| 人机共驾默认     | MVP：信号推送 + 一键确认；V1：小仓位自动；V2：按策略分账户全自动                     |
| 可复盘        | 每笔单保存：四维快照、模型理由、规则校验结果、成交与滑点                              |

> 市场上没有「永远正确的交易神模型」。可行产品是：**强模型做研判 + 强规则做执行 + 强风控做兜底**。

## 3. 模型选型（交易/金融向）

### 3.1 推荐架构：双模型（研判层 + 盘面层）

| 角色               | 候选（2026 口径）                                                                                 | 职责                                               |
| ---------------- | ------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| **主研判模型（LLM）**   | 优先：**Claude Opus 5.5**（金融/会计类榜单领先档）或 **Gemini 3.8 Flash / GPT‑6 Astra**（金融 Agent / 交易直觉评测强） | 消化新闻、事件、宏观、情绪文本；输出结构化 JSON：状态、方向偏见、事件冲击等级、是否切换策略 |
| **盘面/时序辅模型（可选）** | **Kronos** 类 K 线基础模型，或自研特征模型                                                                | 箱体、放量、针刺、波动率 regime；输出技术特征分数，不单独下单               |
| **执行层**          | 非 AI：Python 规则引擎 + 交易所 API                                                                  | 下单、对冲对齐、网格、止损、熔断                                 |

### 3.2 选型落地建议

- **MVP**：单一顶级 LLM（Opus 5.5 或同级）+ 规则引擎，成本可控。  
- **生产**：主模型（高质量推理）+ 快模型（低延迟扫新闻/情绪）+ 盘面特征服务。  
- **禁止**：让模型直接吐「市价买入 10 BTC」而不经风控 schema 校验。

### 3.3 模型输出必须是结构化契约（示例）

```json
{
  "ts": "2026-10-08T02:00:00Z",
  "regime": "RANGE",
  "assets": {
    "BTC": { "bias": "neutral", "box": [82000, 85000], "confidence": 0.72 },
    "XAU": { "bias": "funding_arb", "confidence": 0.81 }
  },
  "scores": {
    "technical": 0.55,
    "news": 0.40,
    "event": 0.65,
    "sentiment": 0.35
  },
  "event_shock": "medium",
  "allowed_strategies": ["GRID_BTC", "XAU_FUNDING"],
  "blocked_strategies": ["OPP_TREND_LONG"],
  "rationale_zh": "纪要偏鹰已定价；BTC仍在82-85箱；无海峡协议突破",
  "valid_until_min": 30
}
```

## 4. 四维监控体系

### 4.1 技术面（Technical）

| 数据                    | 频率        | 用途          |
| --------------------- | --------- | ----------- |
| OHLCV（1m/5m/1h/4h/1d） | 实时        | 箱体、突破、针刺、放量 |
| 现货–永续基差、资金费率          | 每结算/每分钟   | 黄金/加密费率套利开关 |
| 波动率、ATR、成交量分位         | 实时        | 网格间距、止损宽度   |
| ETF 日流（BTC/ETH）       | 日更 + 盘中占位 | 趋势确认/失效     |

**输出特征：** 箱上下沿、是否放量针刺、是否有效突破、费率 APR、基差偏离。

### 4.2 消息面（News）

| 源类型  | 示例                         | 门槛（可沿用现有监控）          |
| ---- | -------------------------- | -------------------- |
| 宏观利率 | FOMC、点阵图、鲍威尔讲话、FedWatch 跳变 | 决议/点阵/显著改口/概率大幅跳变才升权 |
| 地缘能源 | 伊美、霍尔木兹协议/重开/再关闭           | 正式协议或海峡状态突变才升权       |
| 监管   | SEC/CFTC/稳定币重大落地           | 明确利多利空加密才升权          |
| 资产特有 | ETF 异常流、主网事故、解锁            | ≥阈值才升权               |

**AI 任务：** 去重、分级（噪声/观察/行动）、映射到资产冲击（BTC/ETH/XAU）。

### 4.3 事件面（Event）

日历驱动，提前进入「事件窗口」：

- 美联储：决议、纪要、重要官员讲话  
- 美国数据：CPI、PCE、非农、ISM  
- 国债拍卖：10Y 等（影响实际利率/金/币）  
- 加密：ETF 数据点、期权到期、大型解锁

**规则：** 事件前 N 分钟降杠杆 / 收紧网格 / 暂停机会单；事件后根据冲击等级决定是否交易。

### 4.4 情绪面（Sentiment）

| 指标              | 含义          |
| --------------- | ----------- |
| 资金费率、多空比、OI 变化  | 拥挤度、轧空/洗多风险 |
| 清算热力（多/空）       | 针刺后是否继续     |
| ETF 净流、稳定币净增    | 风险偏好        |
| 社交/新闻情绪分数（模型打分） | 辅助，不单独触发开仓  |

**合成：** `sentiment_score ∈ [-1, 1]`，与技术/消息/事件加权后进入状态机。

### 4.5 四维融合（简化）

```
regime_score = w_t*Tech + w_n*News + w_e*Event + w_s*Sentiment
```

默认权重（可调）：技术 35% / 事件 25% / 消息 20% / 情绪 20%。  
**事件冲击 ≥ high 时：** 事件权重临时升至 40%+，并强制 `RISK_OFF` 或只保留套利。

## 5. 三大策略产品化

### 5.1 策略 A — 黄金费率套利（XAU Funding Arb）

| 项      | 规格                                              |
| ------ | ----------------------------------------------- |
| 逻辑     | 费率偏正：买现货（或等价多头）+ 1:1 空永续，吃资金费                   |
| 启用条件   | `regime` 允许套利；XAU 费率 7 日均 APR ≥ 阈值（如 6%）；基差在安全带 |
| 退出     | 费率转负连续 N 次；基差偏离超限；保证金率告警                        |
| 预期（参考） | 净年化常见约 **6%–12%（名义）**，非保证                       |
| 风控     | 名义对齐误差 ≤ 1%；单所深度不足禁止开；禁止加方向单边                   |

**机器人模块：** `FundingArbEngine`（确定性）+ AI 仅做「是否适合继续挂着」的巡检。

### 5.2 策略 B — 加密机会单（箱体/趋势机会）

| 项    | 规格                                                         |
| ---- | ---------------------------------------------------------- |
| 逻辑   | 判牛/熊/箱；在箱底或箱顶出现**放量针刺并收回**后，做多现货或做空                        |
| 启用条件 | `TREND` 或明确箱沿信号；`event_shock` ≠ high；情绪未极端拥挤反向             |
| 硬止损  | 价格 **1.5%–2.5%**，或针刺极值外 **0.8%–1.2%**；账户风险 **0.5%–1.5%/笔** |
| 止盈   | 第一目标 **+3%～5%**（或箱中/对侧沿）分批；盈亏比目标 ≥ 1.5                     |
| 失效   | 破箱收不回 / 宏观黑天鹅 → 市价离场                                       |

**AI 职责：** 识别「真假突破」「是否放量」「当前箱是否有效」。  
**规则职责：** 算仓位、挂止损止盈、禁止无止损开仓。

### 5.3 策略 C — 震荡网格（Grid）

| 项    | 规格                                               |
| ---- | ------------------------------------------------ |
| 逻辑   | `RANGE` 下在箱内低买高卖（可多空网格）                          |
| 区间   | 动态箱（如 BTC 82–85）内外各留缓冲                           |
| 间距   | 0.3%–0.8%（随 ATR 自适应）                             |
| 硬熔断  | 破下沿再走 **1%–1.5%** 平多网格；破上沿对称平空网格（约箱宽 25%–40% 外扩） |
| 账户熔断 | 网格累计浮亏达本金 **2%–4%** 全停                           |

**AI 职责：** 宣布进入/退出 RANGE，调整箱沿。  
**禁止：** 破箱后摊平加格。

### 5.4 策略调度矩阵

| 状态        | A 黄金套利    | B 机会单    | C 网格 |
| --------- | --------- | -------- | ---- |
| ARBITRAGE | ✅ 主       | ❌        | ❌/极小 |
| RANGE     | ✅ 可并行     | ❌ 或极小观察单 | ✅ 主  |
| TREND     | ✅ 可保留     | ✅ 主      | ❌    |
| RISK_OFF  | 仅可平仓/保守套利 | ❌        | ❌    |

## 6. 系统架构（可行落地）

```
┌─────────────────────────────────────────────────────────┐
│  Data Plane（数据采集）                                   │
│  行情WS / 费率 / OI清算 / ETF / 新闻RSS·API / 经济日历     │
└───────────────────────┬─────────────────────────────────┘
                        ▼
┌─────────────────────────────────────────────────────────┐
│  Feature Plane（特征）                                    │
│  技术指标 · 箱体识别 · 情绪因子 · 事件窗口标记              │
└───────────────────────┬─────────────────────────────────┘
                        ▼
┌─────────────────────────────────────────────────────────┐
│  AI Plane（研判）                                         │
│  快模型扫新闻情绪 → 主模型四维融合 → 输出 Regime JSON      │
└───────────────────────┬─────────────────────────────────┘
                        ▼
┌─────────────────────────────────────────────────────────┐
│  Strategy Plane（策略）                                   │
│  A FundingArb │ B Opportunity │ C Grid │ 调度器           │
└───────────────────────┬─────────────────────────────────┘
                        ▼
┌─────────────────────────────────────────────────────────┐
│  Risk & Execution Plane（风控与执行）                      │
│  仓位/杠杆/止损/熔断校验 → 交易所API → 成交回报            │
└───────────────────────┬─────────────────────────────────┘
                        ▼
┌─────────────────────────────────────────────────────────┐
│  Control Plane（人机）                                     │
│  App/Telegram：信号推送 · 确认 · 日志 · 日报 · 紧急停机     │
└─────────────────────────────────────────────────────────┘
```

### 6.1 建议技术栈（MVP）

- 语言：Python 3.11+  
- 行情/交易：交易所官方 API（如 Binance / Bybit；密钥权限最小集）  
- 队列：Redis（信号、事件、去重）  
- 存储：Postgres（订单/快照）+ 对象存储（原文新闻）  
- 调度：已有小时级新闻监控可并入 Event/News Worker  
- 前端：Telegram Bot 或简易 Web 控制台

## 7. 风控总闸（产品级）

| 闸门          | 默认建议                                   |
| ----------- | -------------------------------------- |
| 单笔账户风险      | ≤ 1%（机会单）                              |
| 日亏损熔断       | −3%～−5% 停机                             |
| 总杠杆         | 套利 ≤ 2x 有效；机会单 ≤ 5x；网格 ≤ 2x            |
| 相关性敞口       | BTC+ETH 同向名义上限                         |
| AI 失效       | 模型超时/JSON 非法 → 保持上状态或 RISK_OFF，不得新开机会单 |
| Kill Switch | 一键平仓 + 撤网格 + 停 API                     |

## 8. 产品形态与版本路线

### MVP（4–6 周量级工作量口径：模块交付，非日历承诺）

1. 数据：XAU + BTC 行情、费率、基础新闻/日历  
2. AI：四维 JSON 输出 + Telegram 推送  
3. 策略：先上 **A 黄金套利（半自动）** + **C 网格仿真**  
4. 风控：硬止损/熔断/日志

### V1

- B 机会单小仓实盘（确认模式）  
- ETF/清算/FedWatch 接入  
- 回测与仿真报告

### V2

- 多所套利、自适应箱体、策略资金权重自动分配  
- 完整审计面板与周报（可对接现有 `weekly-trade-summary`）

3. 模式：`观察 / 确认下单 / 自动（限额内）`
